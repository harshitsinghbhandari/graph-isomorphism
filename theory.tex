\section{Graph Isomorphism}

Let $G_A$ and $G_B$ be simple undirected graphs with adjacency matrices
$A,B\in\{0,1\}^{n\times n}$.
They are isomorphic if and only if there exists a permutation matrix
$P\in\Pi_n$ such that
\begin{equation}
    AP = PB.
\end{equation}

This is equivalent to $P^\top A P = B$.
The formulation $AP=PB$ is the one used for verification in the codebase.

\section{Birkhoff Relaxation}

The discrete feasible set $\Pi_n$ is relaxed to the Birkhoff polytope
\begin{equation}
    \mathcal{B}_n =
    \left\{
    X \in \mathbb{R}^{n\times n} :
    X_{ij}\ge 0,\ 
    \sum_j X_{ij}=1,\ 
    \sum_i X_{ij}=1
    \right\}.
\end{equation}

By the Birkhoff-von Neumann theorem, the vertices of $\mathcal{B}_n$ are
exactly the permutation matrices.
Thus the relaxation keeps all exact isomorphism witnesses while allowing the
solver to search a continuous convex set.

\section{Current Objective}

The implemented solver optimizes
\begin{equation}
\boxed{
    \min_{X\in\mathcal{B}_n}
    w_C\langle C,X\rangle
    +
    w_Q\|AX-XB\|_F^2
}
\end{equation}
with default weights $w_C=w_Q=1$.

\subsection{Adjacency Term}

The adjacency term is
\begin{equation}
    Q(X)=\|AX-XB\|_F^2.
\end{equation}
If $X=P$ is a true isomorphism, then $Q(P)=0$.
This term is the direct continuous analog of the exact condition $AP=PB$.

\subsection{Degree-Profile Term}

Let
\begin{equation}
    d^A_i=\sum_k A_{ik},\qquad d^B_j=\sum_k B_{jk}
\end{equation}
be degrees, and
\begin{equation}
    s^A_i=\sum_k A_{ik}d^A_k,\qquad
    s^B_j=\sum_k B_{jk}d^B_k
\end{equation}
be neighbor-degree summaries.

The raw compatibility cost is
\begin{equation}
    C^{raw}_{ij}
    =
    \alpha |d^A_i-d^B_j|
    +
    \beta |s^A_i-s^B_j|,
\end{equation}
with default $\alpha=1.0$ and $\beta=0.35$.
The code normalizes $C^{raw}$ by its maximum absolute entry when nonzero.

\section{Convexity}

The current objective is convex.
The feasible region is convex, $\langle C,X\rangle$ is linear, and
$\|AX-XB\|_F^2$ is the squared norm of a linear function of $X$.

Therefore the active model does not require Gurobi's non-convex QP mode.
Future terms may change this, but the current source-of-truth solver is a
convex QP.

\section{Score and Certificate}

After solving, the code reports
\begin{equation}
    I=\exp(-\lambda Z^*)
\end{equation}
with default $\lambda=0.1$.
This is a similarity score only.

The binary positive certificate is obtained separately.
The relaxed matrix $X^*$ is rounded to a permutation candidate $P^*$ by the
hyperplane-rounding routine, and the code accepts isomorphism only if
\begin{equation}
    AP^*=P^*B
\end{equation}
holds exactly.

If the equality fails, the method has not certified isomorphism.
That is not a proof of non-isomorphism.

\section{What Is Not Currently Implemented}

The current active solver does not include:
\begin{itemize}[leftmargin=*]
    \item higher-order terms $\|A^kX-XB^k\|_F^2$ for $k>1$;
    \item spectral or Grassmannian eigenspace alignment;
    \item entropy regularization;
    \item Weisfeiler-Lehman node features;
    \item exact cutting planes for non-isomorphism.
\end{itemize}

These are reasonable future extensions, but they should not be presented as
current implementation.
